# Phase Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Phase" tab (after Business) with the phase verdict and a growth-cycle diagram, a revenue & operating-cash-flow chart, and two computed Payouts flip cards.

**Architecture:** `phase_payouts.py` holds the pure maths (payout cards, chart series, caption) on the dicts from the existing EDGAR fetchers; `phase_page.py` renders HTML (phase card, growth-cycle SVG, sections) and the Plotly figure; `streamlit_app.py` wires a new tab.

**Tech Stack:** Python 3.11+, Streamlit 1.54, Plotly 6.5, pytest.

**Spec:** `docs/superpowers/specs/2026-09-28-phase-tab-design.md`

## Global Constraints

- Tab order: `["Overview", "Pre-Scan", "Business", "Phase", "Moat", "Risk", "Fundamentals", "DCF", "Reverse DCF", "Peer Comparison", "Dividend", "History"]`.
- Six phases, exactly: `PHASES = ((1, "Startup"), (2, "Hypergrowth"), (3, "Self Funding"), (4, "Operating Leverage"), (5, "Capital Return"), (6, "Decline"))`.
- House style: sections via `question_cards.section_html(label, inner)`; flat inner cards background `var(--qc-inner, color-mix(in srgb, var(--text) 4%, var(--card)))`, 16px radius; widgets live in keyed containers styled like `.st-key-qc_ov_price` (see streamlit_app.py global CSS).
- Streamlit HTML rules: CSS on ONE line via `question_cards.css(...)`; all dynamic text through `question_cards.esc()`; HTML starts with a tag; missing → `—`; never crash (every render path wrapped so a failure shows a caption, not a traceback).
- Units: fundamentals / cash-flow amounts in $M, `fund["shares"]` raw count, per-share values in dollars. A missing line item in a fiscal year that exists = 0 for cash-flow lines (same rule as overview_metrics).
- Payout option labels exactly: buybacks `("No", "Yes & diluting", "Yes & shrinking")`, dividend `("No", "Yes & stable", "Yes & growing")`; thresholds: shrinking when shares fell ≥ 1% over 5 years; growing when per-share dividend CAGR over 3 years ≥ 2%.
- Chart ranges `("5Y", "10Y")`, default `"5Y"`.
- Tests offline; `python3 -m ruff check .` clean; full suite has one known unrelated failure (`tests/test_market_data.py::test_fetch_dividend_history_full_5y_payer`).

### Task 1: `phase_payouts.py` — payout cards, chart series, caption

**Files:** Create `phase_payouts.py`, `tests/test_phase_payouts.py`.

**Interfaces (produces):**
- `PAYOUTS: question_cards.CardSet` with `title="Payouts"`, `directions=None`, `items=(("buybacks", "Buybacks", "Are they buying back stock?", ("No", "Yes & diluting", "Yes & shrinking")), ("dividend", "Dividend", "Do they pay a dividend?", ("No", "Yes & stable", "Yes & growing")))` — check `question_cards._item` / `flip_card_html` for the exact tuple shape `(key, name, question, options)` and match it.
- `buyback_card(fund, cashflow, price) -> dict` and `dividend_card(fund, cashflow, income_or_none, price, net_cash_m) -> dict`, each returning `{"source", "pick", "summary", "points": [3 × {"label","text"}]}` usable by `question_cards.flip_card_html(PAYOUTS, card, theme)`. Rules and sentences exactly as in the spec's Payouts section. Fiscal year = `overview_metrics`' fiscal year (last year with revenue; reuse its helpers rather than duplicating). Market cap = price × fiscal-year shares / 1e6 (`overview_metrics.shares_at_fiscal_year`); yields `—` without price.
- `revenue_ocf_series(fund, years: int) -> tuple[list[int], list[float|None], list[float|None]]` — the last `years` fiscal years that have revenue, with revenue and cfo ($M).
- `revenue_ocf_caption(years, revenue, cfo) -> str` — the spec sentence; CAGR over n = len−1 years only when first and last revenue > 0 (else omit that clause); `""` with fewer than 2 years.

- [ ] **Step 1:** Write `tests/test_phase_payouts.py` with fixtures shaped like `tests/test_overview_metrics.py` (years 2016–2026). Cases: buybacks none → pick 0 + "No buybacks in the last five years."; buybacks with shares down 4% → pick 2 and "4.0% fewer shares than FY2021"; buybacks with shares up 2.3% → pick 1 and "2.3% more shares"; untagged buyback years count as 0; buyback yield uses last-year amount / mcap; dividend none → pick 0 with the three "No" back points; dividend DPS growing 5%/yr → pick 2 and "5.0% a year"; flat DPS → pick 1; price None → yield "—"; every card has exactly 3 points and a non-empty summary; `question_cards.flip_card_html(PAYOUTS, card, theme)` renders without error (theme dict with keys text, text_muted, divider — see tests of risk_cards for a theme fixture). Series/caption: 5Y returns 6 points? — define: `years=5` returns the last 5 fiscal years; caption for revenue 100→146.4 over 4 steps says "10.0% a year over 4 years"; negative first revenue omits the growth clause; cfo positive count correct.

### Task 2: `phase_page.py` — phase card, growth-cycle SVG, sections, figure

**Files:** Create `phase_page.py`, `tests/test_phase_page.py`.

**Interfaces (produces):**
- `PHASES` (global constraint).
- `phase_number(analysis_text: str | None, scorecard_text: str | None) -> int | None` — score from `prescan_render.parse_verdict_section(analysis_text)` when its `out_of == 6` and 1 ≤ score ≤ 6; else Scorecard JSON (fenced) `phase.number`; else None. Never raises.
- `phase_section_html(analysis_text, scorecard_text, theme) -> str` — `section_html("Phase", …)` with two equal-height flat cards in a 2-column grid (1 column below 800px): **Phase Analysis** (badge: large number in an accent circle + phase name; then the parsed `summary` as lead and the parsed bullets — reuse how `risk_cards._verdict_card` / `question_cards.summary_card_html` render lead + bullets where practical) and **Growth cycle** (the SVG). No analysis and no scorecard phase → the spec's notice text in the Phase Analysis card and the diagram without highlight.
- `growth_cycle_svg(current: int | None) -> str` — inline `<svg viewBox="0 0 600 220">` with 6 equal columns, column labels "1 Startup" … "6 Decline" (small text), a zero baseline, three smooth paths (Revenue, Profits, Payouts) as described in the spec, a tiny legend, and when `current` is set a translucent `var(--accent)` band over that column plus a filled circle with the number above it. Colours via CSS variables (`var(--accent)`, `var(--text-muted)`, `#5b6cff` for Payouts). No external assets.
- `revenue_ocf_figure(years, revenue, cfo, theme) -> plotly Figure` — two lines (Revenue in `theme["accent"]`, Operating cash flow `#5b6cff`), markers, x = fiscal years as `FY2021` strings, y in $ with `tickprefix="$"` and values shown as B/M via hovertemplate, height 320, transparent background, legend top-left horizontal.
- `payouts_section_html(buyback_card, dividend_card, theme) -> str` — `section_html("Payouts", question_cards.grid_html(PAYOUTS, [buyback_card, dividend_card], theme))` (check grid_html's signature and CSS; the grid is 2-up).

- [ ] **Step 1:** Tests: phase_number from a verdict text `"**Phase: Capital return · 5/6**\n\nLead sentence.\n\n- **A**: x\n- **B**: y\n- **C**: z"` → 5; out_of ≠ 6 → falls back to scorecard ```json {"phase": {"number": 4}}``` → 4; garbage → None; section HTML contains "Phase Analysis", "Growth cycle", "Capital Return", the lead sentence, no raw `$`, starts with `<`, no newline inside `<style>`; notice text when nothing parses; `growth_cycle_svg(5)` contains six labels and exactly one highlight band, `growth_cycle_svg(None)` none; figure has 2 traces with the given y; payouts section contains both questions.
- [ ] **Step 2–5:** fail → implement → pass (+ ruff) → commit `Phase: page HTML, growth-cycle diagram, chart`.
